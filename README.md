# Atividades de Desenvolvimento Web

Este repositório foi criado para armazenar e organizar os trabalhos e atividades desenvolvidos durante as aulas da disciplina de **Desenvolvimento Web: Introdução ao HTML, CSS e Javascript**, da **Professora: Renata Porto Gransoti**. 

O objetivo principal é registrar a evolução do aprendizado prático em estruturação e estilização de páginas web.

##  Tecnologias Utilizadas
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização, layout e design responsivo.
* **JavaScript:** (A ser introduzido nas próximas etapas).
